# 小师弟求职 · 设计系统 1.1

适用于资料维护页、Chrome 侧栏、独立 HTML 与 Excel 导出。设计依据和实现分开记录：来源不是本项目已通过可用性测试的证据。

## 信息分层

常驻只放当前任务：搜索、分类、记录、填写内容、保存状态。副操作放到对象旁：字段设置、经历操作、分类设置。跨页面的低频操作放到右上角设置：配色、历史、帮助、诊断。破坏性操作再进一层，并明确确认。

这对应渐进披露，而不是删除必要安全信息。目标网站来源、未保存错误、导入覆盖和敏感字段确认仍在发生动作时直接显示。主页面不重复产品标语、模块大标题和全套教程。

https://www.nngroup.com/articles/progressive-disclosure/

## 尺寸与层级

| Token / 组件 | 规格 | 目的 |
|---|---|---|
| 间距 | 4 / 8 / 12 / 16 / 24px | 统一密度，不给每个组件单独拍脑袋 |
| 正文 / 标签 | 13px / 12px，行高约 1.5 | 压缩容器而非无限缩小文字 |
| 标题 / 图标 | 14px / 16px | 保留层级，不设置大幅标题 |
| 图标按钮 | 28px 点击区，触摸环境适当增大 | 图形与可点面积分离 |
| 常规按钮 / 输入 | 32px / 最小 36px 高 | 操作一致、输入有边界 |
| 管理页顶栏 / 侧栏顶栏 | 48px / 44px | 品牌不再占独立大块 |
| 分类导航 | 管理页 168px、侧栏 78px，窄侧栏 64px | 给主要内容更多宽度 |
| 导航收起 | 46px | 保留短标记、完整名称 tooltip 和 accessible name |
| 管理页字段 | 宽屏 3 列，中屏 2 列，窄屏 1 列 | 长文本独占一行，不受固定最大内容宽度限制 |
| 侧栏字段 | 标签 + 值 + 行级操作 | 不将每个字段画成大卡片 |
| 圆角 | 6px 控件、8px 记录 | 结构清楚但不过度装饰 |
| 动效 | 160ms 折叠 / 状态变化 | 支持 reduced-motion；折叠内容 inert |

CSS 来源为 `extension/ui/style.css`。配色 token 单独在 `extension/shared/design-tokens.js`，偏好持久化单独在 `extension/ui/theme.js`。不能在业务代码散落任意颜色。

## 六套高亮色

使用 Radix Colors 官方 sRGB 色阶。主体仍是中性底色，高亮色只作用于选中项、焦点、主按钮、主题预览及导出表格，不改变危险操作的语义色。

| 名称 | Radix 色系 | 主色 | hover / 强文字 | 浅背景 | 边界 |
|---|---|---|---|---|---|
| 蓝色 | blue | #0D74CE | #113264 | #E6F4FE | #8EC8F6 |
| 青绿 | teal | #008573 | #0D3D38 | #E0F8F3 | #83CDC1 |
| 紫色 | violet | #6550B9 | #2F265F | #F4F0FE | #C2B5F5 |
| 玫红 | ruby | #CA244D | #64172B | #FEEAED | #EFACB8 |
| 暖棕 | bronze | #7D5E54 | #43302B | #F6EDEA | #D3BCB3 |
| 石墨 | slate | #60646C | #1C2024 | #F0F0F3 | #CDCED6 |

主色选用 step 11，强文字/hover 选 step 12，浅背景取 step 3，边界取 step 8。这是本产品在 Radix 原始色阶上的语义映射，不声称完全照搬其默认用途。主要考虑紧凑界面中的小号白色按钮文字对比度。每套色系均有数值对比测试，不只看品牌名。

## 中性与状态色

文字 #1C2024，次文字 #60646C，页面 #F9F9FB，白色表面 #FFFFFF，普通分隔 #E0E1E6，输入边界 #8B8D98。危险色 #B42335 / #FFF0F1，保存状态 #28684A。不能只用颜色表达错误或选择：同时保留文字、边线、aria-pressed / aria-current。

## 可访问性与误操作

普通文字对比度目标至少 4.5:1；图标按钮至少 24px 的可点面积目标。主色文字组合、键盘操作、窄屏和 reduced-motion 已有针对性测试，不等于完整 WCAG 认证。真实屏幕阅读器、浏览器原生 200% 缩放、系统高对比度仍需人工验证。

WCAG 2.2：
https://www.w3.org/TR/WCAG22/

所有图标按钮有可读名称和 tooltip。字段编辑按钮在 hover 或 focus-within 出现，键盘能访问，触摸布局不会只靠悬停。搜索尊重输入法组合输入；未变更的目标轮询不重建按钮，避免夺走键盘焦点。

## 性能是组件规范的一部分

记录默认折叠时不预创建全部字段组件，第一次展开才挂载。折叠后保留已创建的输入组件和数据，避免反复开关丢失编辑状态。搜索先展示 200 个匹配字段，继续操作可看全部，并始终显示总数。不是只搜索前 200 项。

不引入全新前端框架、远程 UI 库、字体文件或 CDN；不改动填表信任边界和已有资料存储协议。
