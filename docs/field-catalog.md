# 完整字段目录

20 个可选模块、230 个字段。以下为默认模板，不限制用户自行添加、改名、删除或分组。所有字段均可留空。

## 基本信息（常用，24 项）

**常用资料**：姓名；英文名；性别；手机号码；电子邮箱；当前所在城市；个人网站；作品集链接。

**证件与个人状态**：出生日期〔敏感〕；国籍 / 地区；民族；政治面貌；籍贯；户籍所在地；生源地；证件类型；证件号码〔敏感〕；婚姻状况〔敏感〕。

**地址与其他**：通讯地址〔敏感〕；邮政编码；微信号；备用电话；个人照片文件名（仅备注）；简历附件文件名（仅备注）。

## 求职意向（常用，15 项）

**申请偏好**：目标岗位；目标职类；意向行业；意向公司；意向城市；求职类型（校招 / 社招 / 实习）；工作方式（现场 / 混合 / 远程）。

**到岗安排**：最早到岗日期；每周可实习天数；可实习月数；预计毕业时间；期望薪资〔敏感〕；是否接受调剂；是否接受出差；工作许可 / 签证状态。

## 教育经历（常用，24 项）

**学历信息**：学校名称；学院；专业名称；学历；学位；培养方式；学习形式；学校所在城市；入学时间；毕业时间。

**学业表现**：GPA；GPA 满分；平均成绩；专业排名；专业总人数；排名百分比；主修课程；研究方向；导师姓名；班级。

**补充资料**：毕业论文 / 毕业设计；学习经历说明；第二学位 / 辅修；学历认证状态。

## 工作经历（常用，20 项）

**任职信息**：公司名称；所属行业；公司性质；公司规模；部门名称；岗位名称；工作性质；工作城市；开始时间；结束时间；是否至今。

**工作内容**：岗位职责；重点业绩 / 量化结果；技术栈 / 方法工具。

**补充信息**：职级；离职原因〔敏感〕；薪资信息〔敏感〕；汇报对象；证明人姓名〔敏感〕；证明人电话〔敏感〕。

## 实习经历（常用，16 项）

**实习信息**：公司名称；部门名称；岗位名称；工作城市；实习类型；开始时间；结束时间；是否至今；每周出勤天数。

**实习内容**：实习职责；成果与贡献；技术栈 / 使用工具。

**补充信息**：指导人；证明人电话〔敏感〕；转正情况；离职原因〔敏感〕。

## 项目经历（常用，15 项）

**项目概况**：项目名称；项目类型；所属组织；担任角色；开始时间；结束时间；是否至今；团队规模；项目链接；代码仓库。

**项目内容**：项目背景 / 目标；个人职责；实施过程 / 难点；项目成果 / 指标；技术栈 / 工具。

## 校园与学生工作（扩展，8 项）

**组织信息**：组织 / 社团名称；担任职务；所属学校；开始时间；结束时间；是否至今。

**职责成果**：职责与工作内容；成果与影响。

## 奖项与荣誉（常用，10 项）

**奖项信息**：奖项名称；奖项类别；获奖等级；奖项级别；颁发单位；获奖时间；个人 / 团队；参赛人数 / 排名。

**补充说明**：奖项描述；证明链接。

## 专业技能（扩展，6 项）

**技能信息**：技能名称；技能类别；掌握程度；使用年限。

**能力证据**：应用场景 / 代表成果；证明链接。

## 语言能力（扩展，11 项）

**语言与考试**：语言；听说读写水平；考试 / 等级名称；总分；听力成绩；阅读成绩；写作成绩；口语成绩；考试日期；有效期至。

**说明**：实际使用场景。

## 证书与资质（扩展，8 项）

**证书信息**：证书名称；等级；颁发机构；证书编号〔敏感〕；取得日期；有效期至。

**补充说明**：证书说明；验证链接。

## 科研经历（扩展，10 项）

**课题信息**：课题名称；研究机构；指导教师；研究角色；开始时间；结束时间。

**研究内容**：研究问题；研究方法；个人贡献；成果与影响。

## 论文与专利（少用，10 项）

**成果信息**：成果名称；成果类型；作者 / 发明人排序；期刊 / 会议 / 专利机构；发表 / 授权状态；发表 / 授权日期；DOI / 专利号；公开链接。

**成果介绍**：摘要 / 内容；个人贡献。

## 培训与进修（扩展，7 项）

**培训信息**：课程 / 项目名称；培训机构；培训地点；开始时间；结束时间。

**培训内容**：学习内容；考核与成果。

## 志愿与社会实践（扩展，9 项）

**实践信息**：活动名称；组织单位；担任角色；活动地点；开始时间；结束时间；服务时长。

**实践内容**：职责与内容；成果与影响。

## 作品与链接（扩展，8 项）

**作品信息**：作品名称；作品类别；本人角色；作品链接；附件文件名（仅备注）。

**作品介绍**：作品概述；个人贡献；访问密码（非账户密码）。

## 自我介绍与问答（常用，11 项）

**常用回答**：自我介绍；自我评价；个人优势；待提升之处；申请动机；职业规划；兴趣爱好。

**行为问题**：最有成就感的一件事；遇到的最大挑战；团队协作案例；冲突处理案例。

## 推荐人与紧急联系人（少用，7 项）

**联系人信息**：姓名〔敏感〕；关系；所在单位；职务；联系电话〔敏感〕；电子邮箱〔敏感〕。

**补充说明**：联系说明〔敏感〕。

## 家庭成员（少用，5 项）

**家庭成员**：姓名〔敏感〕；与本人关系〔敏感〕；工作单位〔敏感〕；职务〔敏感〕；联系电话〔敏感〕。

## 网申补充与声明（少用，6 项）

**补充材料**：其他说明；信息来源；内推码；是否曾在该企业任职；利益冲突 / 亲属任职说明〔敏感〕；其他需要说明的情况〔敏感〕。
