## 名称

小师弟求职

## 简介

在本机整理求职资料，按分类快速取用。支持可编辑的 Excel 双向导入导出，在已授权网页中逐项填写，不自动提交。

## 详细介绍

把姓名、联系方式、教育和工作经历集中放在资料维护页。打开招聘网站后，在侧栏找到对应经历，点选网页输入框，再点一项资料即可尝试填写。

分类、经历、字段和分组都能按自己的需要维护。常用信息先展示，其他内容按需添加；多段经历可以折叠，长文本支持完整查看和复制。Excel / JSON 可以导出，也能导回继续维护。长期备份可使用口令加密文件。

本版本没有账号、广告或自动遥测，不将整份资料上传到服务器。资料保存在本机，本地存储未加密。Excel/JSON 和系统剪贴板中的内容请妥善保管。敏感字段可遮挡，并在使用前再次确认。

操作由你控制：每次只填一个字段，不批量投递、不自动提交。部分网站的复杂控件需要手动复制粘贴。不会解析任意 PDF/Word/TXT 简历，不会自动上传照片或附件，不承诺兼容全部招聘网站。

## 单一用途声明

帮助求职者在本机结构化维护个人申请资料，并在其主动授权的网页中逐项取用填写。

## 权限说明

storage：保存资料和有限历史。activeTab：用户点击后临时访问当前网页。scripting：注入本地填表脚本。sidePanel：展示原生侧栏。clipboardWrite：用户点击复制时写系统剪贴板。

无需永久读取所有网站，无后台批量申请或隐藏自动提交。商店的数据处理问卷应准确披露“本地处理用户主动提供的个人信息”，不要因为没有上传服务器就回答成完全不处理数据。
