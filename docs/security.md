# 安全与隐私设计说明

本文件描述实现，不是独立安全审计或“绝对安全”承诺。

## 数据范围与去向

用户手动录入或主动选择的文件包含个人信息。扩展存储在 `chrome.storage.local`；独立 HTML 存储在该浏览器的 localStorage。都不是加密保险箱。侧栏遮挡和使用前确认降低误操作，不阻止有本机权限的软件、恶意浏览器扩展、设备备份或操作系统账户读取可接触的数据。

招聘网站只能收到用户明确选中的值，但网站及其脚本能读取写入其表单的内容。复制内容进入系统剪贴板，操作系统剪贴板同步也可能继续传播。产品没有账号、遥测、广告、AI 调用或网络客户端，应用编辑流程的浏览器测试也没有观察到 HTTP/HTTPS 请求；这不代表被填写的第三方网站没有网络活动。

## 权限最小化

| 权限 | 用途 |
|---|---|
| storage | 保存用户资料与有限本地历史；后台启动时设置 TRUSTED_CONTEXTS |
| activeTab | 用户调用扩展后临时访问当前页，不申请 `<all_urls>` |
| scripting | 向当前授权页面注入本地打包的隔离世界内容脚本 |
| sidePanel | 浏览器原生侧栏 UI |
| clipboardWrite | 用户明确点击复制时写剪贴板；没有读取剪贴板权限 |

没有广泛 host_permissions、自动 content_scripts、externally_connectable、web_accessible_resources、cookies、webRequest、历史记录或调试器权限。使用 tabs 的查询/生命周期 API 不意味着申请了读取全量标签内容的 tabs 权限。

## 来源隔离

后台只接受本扩展 ID 且精确为 manager.html / sidepanel.html 的资料操作。内容脚本不能通过消息加载、保存、导出或删除整个库。内容脚本的 FOCUS 信息必须有真实 sender tab 与 documentId；网页来源由 sender URL 提取，不能由请求伪造。单值写入绑定活动标签及文档 ID。相关分支已用模拟 Chrome API 单元测试；真实浏览器安全边界与扩展进程隔离仍需原生测试。

## 文件与输出防护

资料结构严格校验并重建已知字段，禁止未知版本、重复 ID、非法 XML 控制字符、超限内容与非字符串值。XLSX 解压限制文件数、压缩方式、总输出和单项输出；检查路径穿越、重复路径、CRC、加密/ZIP64 等不支持特性。XML 拒绝 DTD/ENTITY；不执行公式、宏、外链。UI 使用 textContent 与 DOM 构建，不把用户值拼成 HTML。Excel 导出使用显式字符串，原文开头的等号不是公式。

这些限制故意偏保守。导入失败应返回错误而不是“智能修复”敏感证件号。该 XLSX 解析器仅为本产品协议实现，尚未经过通用格式模糊测试或独立渗透审查。

## 备份加密

只有 `.applyvault` 文件使用 Web Crypto：PBKDF2-HMAC-SHA256、310000 次迭代、16 字节随机盐，派生 AES-256-GCM 密钥；12 字节随机 IV，固定附加认证数据。口令不持久化。密文被篡改、口令错误或参数不匹配时失败。口令强度、设备安全和泄漏风险仍由实际使用环境决定。此参数描述不是密码学审计结论。

## 仍需的安全验证

原生 Chrome 中网页不能读取完整资料、未授权页面不能接收消息、受信任上下文限制实际生效；多窗口与 service worker 重启；恶意页面操纵焦点/DOM；同源/跨源 frame 组合；后台保存异常；文件解压边界的独立审查。未完成这些验证前不得宣传为“审计通过”。不要使用禁用企业安全策略或忽略浏览器限制的方式伪造通过。

发现问题时提供最小复现与脱敏诊断，不发送真实简历、证件号、口令或未脱敏浏览器配置。运营者应在公开销售前建立安全问题接收渠道。
