# 使用小师弟求职

## 整理资料

点「编辑资料」，左侧选一个分类，右边填写。页面右下方或底栏显示「已保存」后再关闭。

增加一段经历用「添加记录」。每段右上方的更多按钮可以改名、复制、上移、下移和删除。字段旁的编辑按钮设置名称、分组、格式或敏感标记。「添加分类」既有预设，也可以自定义。

## 在网页填写

打开招聘网站和插件，点击网页的输入框，再点击侧栏对应资料。上方会显示要填写的目标及网站，先核对它。侧栏中的复制按钮是手动粘贴的备用方式。眼睛按钮看完整长文。完成后仍需自行检查、保存和提交网站表单。

## 找资料

顶部搜索覆盖所有分类，不只搜当前页。可搜公司、经历名、字段名和非敏感内容，多个词之间加空格。Ctrl/Cmd+K 搜索，Esc 返回。超过 200 项结果时点「显示更多结果」。

## 少看不需要的内容

左上角按钮收起分类。经历、字段分组都可以折叠。侧栏默认不显示空值。右上角「设置与帮助」可以开启空项目、换高亮色、查看帮助和历史记录。主界面没有反复出现的教程。

## Excel 往返

导出选择「Excel · 按分类整理」。打开后，一类资料一张工作表，只看「分组」「项目」「填写内容」。修改浅色内容列，保存 `.xlsx`，再导入。导入预览确认后会替换当前资料。

复制整段行可以新增经历；插入整行填写项目名可以新增字段。保留整行/整段的对应关系，不要只排序某几列；隐藏部分不用碰。删行或删工作表等同删相应内容，修改前先备份。

## 备份与设备

普通 Excel / JSON 是明文；「加密备份」用自己的口令加密文件，口令忘了无法恢复。独立 HTML 与插件不自动同步，换电脑、换浏览器或升级前先导出。

显示「未保存」时先导出当前草稿或重试，不要直接关闭。清除资料在设置的「其他操作」内，需要确认，也会清掉本机历史；不会帮你删除已经导出的文件和网站里的内容。
